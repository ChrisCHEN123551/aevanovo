CONNECT YOUR WEBSITE

连接你的 GitHub

使用只授权给官网仓库的授权码发布内容。无需另外设置网站密码。

  1. 打开 GitHub 授权设置 ↗

    会预填名称、30 天有效期及 Contents 读写权限。

  2. 在 Repository access 选择 Only select repositories，仅勾选 aevanovo。

    检查 Contents 为 Read and write。不要选择全部仓库。

  3. 点击 Generate token，复制生成的授权码，粘贴到下方。

仅在此页面内存中使用，刷新或退出后清除。不要把授权码发到聊天里。

READY TO PUBLISH

确认这次更新

这些修改将发布到 aevanovo.eu.cc，所有访客都能看到。

    发布会生成 GitHub 历史版本；官网更新通常需要几分钟。

    A LITTLE GUIDE

    像填表一样，更新官网。

    1. 选择要修改的内容

      左侧切换首页、品牌、技术、五个产品板块或联系方式。中文和英文分别填写。

    2. 查看实际效果

      预览会显示尚未发布的修改。品牌和产品可选传图片，系统会自动压缩。

    3. 连接 GitHub 并发布

      首次使用按“连接 GitHub”的说明创建授权码；过期后重新创建。每次打开页面需重新粘贴授权码。

    草稿和发布有什么区别？

    草稿只保存在当前浏览器；“确认发布”才会保存到 GitHub 并更新官网。换设备前，请先发布或下载内容备份。

    不小心改错了？

    可以导入之前下载的内容备份，再发布。也可以通过 GitHub 的历史版本恢复。
