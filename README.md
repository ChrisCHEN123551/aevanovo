## 发布步骤

1. 新建一个 GitHub 公开仓库，例如 aevanovo-website。
2. 在仓库中选择 Add file → Upload files，上传本文件夹里面的文件（不要把整个文件夹嵌套上传）。
3. 提交文件后，打开 Settings → Pages。
4. 在 Build and deployment 下选择 Deploy from a branch，分支选择 main，文件夹选择 / (root)，点击 Save。
5. 等待发布完成，再在 Pages 设置页面点击 Visit site 查看实际网址。

## 自定义域名 aevanovo.eu.cc

上传包包含 CNAME 文件，内容为 aevanovo.eu.cc。

先在仓库 Settings → Pages 中设置 Custom domain 为 aevanovo.eu.cc 并保存，再通过域名管理平台设置指向 GitHub Pages 的 DNS 记录。目标地址需根据实际 GitHub 用户名或组织名称确定，不包含仓库路径。具体主机记录名称取决于域名管理平台提供的 DNS 区域，不能直接照抄其他域名的设置。

DNS 配置与域名验证完成后，检查 Pages 的 HTTPS 状态并开启 Enforce HTTPS。

自定义域名文档：https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## 当前 DNA 动效实现（2026-10-20 品质与性能更新）

保留原版 DNA 外形、构图和章节联动，素材直接来自原始视频的 241 个原生画面。当前使用 WebP 渐进数据包，桌面 1080px、手机 900px；不再使用旧版 81 帧混合叠加，因此旋转时没有叠帧造成的双重边缘。原生素材中的景深仍保留，不通过过度锐化改变分子轮廓。

页面主线程只负责文字与镜头时序，独立 Worker 完成素材下载解析和异步解码。GPU 在固定视口画布内完成透视、旋转和缩放，纹理仅在画面变化时更新；背景光影保持静态，避免大面积反复重绘。滚动与章节切换共享同一条时间线，停止操作后暂停渲染，切到后台暂停解码。纹理解码窗口有限：手机最多 18 张、桌面最多 26 张，并及时释放淘汰画面。

新增文件：
- media/dna-decoder-20261020.js：同站点后台解码器。
- media/dna-premium-1080-20261020.bin：桌面版原生密度画面包。
- media/dna-premium-900-20261020.bin：手机版原生密度画面包。

首屏正文和原版内置封面不等待动效加载。渐进包优先提供开头、关键章节与分散的预览画面，然后逐步补齐细节。网络较慢时先呈现原始外形，再逐步获得完整流畅度。高品质素材体积高于旧版；每个设备只请求匹配的一种规格，不同时下载两份。

缺少 Worker 或 WebGL 时仍可通过标准图片解码与 Canvas 显示原版旋转，减少动态效果设置下保留原版静态封面。没有额外播放按钮，不依赖自动播放许可、外部视频服务或第三方脚本 CDN。官网内容、所有详情页、咨询提交服务和后台登录方式保持不变。
